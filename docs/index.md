## 職務要約

現在は株式会社 Matataki の CPO としてフルタイムで稼働している。
プロダクトのフルタイムは自分 1 名で、企画・実装推進 まで横断して対応する。

顧客理解を起点に「何を作るか」と「どう実現するか」をつなぎ、
企画・要件定義・設計・デリバリー・改善まで一気通貫で進められる。
基盤コードの立ち上げも、品質を落とさず速くできる。

事業の成長に寄与する役割を志向しつつ、実装にも関わりコードを書き続けたい。

## できること

### プロダクト企画・開発推進

事業方針を踏まえて施策を決め、要件定義からリリース後改善まで推進できる。

→ [SHOWDONE での取り組み](jobs/matataki/matataki-showdone.md)

### アプリケーション開発・設計

TypeScript / Golang / Rails で、要件定義から実装・タスク分解まで一貫して対応できる。
高負荷（秒間 6,000 req）の広告配信では、Redis とメモリキャッシュの 2 層構成で負荷削減を行った。

→ [広告配信の詳細](jobs/qufoo/ad.md)

### 開発プロセス・チーム標準化

Design Docs、レビュー、Cursor ルールなど、チームに適度な規律を入れてデリバリーを加速できる。

→ [医療 SaaS でのプロセス改善](jobs/con/process.md)

### 技術スタック

得意：TypeScript（5 年）、Express / Nest.js / Next.js、AWS / Google Cloud、Docker

その他：Golang、Ruby on Rails、Vue.js / Nuxt.js、Terraform、AWS CDK
