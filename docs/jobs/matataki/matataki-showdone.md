## 概要

株式会社 Matataki の CPO として、B2B リードジェネレーション PF「SHOWDONE」を推進。
2026 年 2 月からフルタイム。プロダクトのフルタイムは自分 1 名で、
バックログ管理・要件定義・実装推進・PR 設計まで一気通貫で担う。

一言で言うと、登録導線 → 相互紹介 → ニーズ流通 → AI オファーまで拡張し、
アポイント獲得のための交流会営業や PR も並行して回した。

過去は検索連動型広告（2023 年）、医療系 SaaS（2024 年 3 月〜2026 年 2 月）と並行。

## 体制

- 営業：社長 1 名
- プロダクト：自分（フルタイム 1 名）＋業務委託

## 主な実績（2026/2〜）

半年で主要機能 30 件超を本番投入。代表例は以下。

### プロダクト

- ゲストチャット・パブリックプロフィールで登録ハードルを下げ、未登録決裁者との接点を取り込んだ
- つながりシェア（相互紹介）とニーズタイムラインを設計・リリースし、紹介起点の商談接続を構築
- 商談報告・BANT・レコメンド・通知で「送る → 返す → 報告する」ループを改善
- AI によるサービス自動登録・オファー文面生成（Langfuse 観測付き）を導入
- PostHog 計測、モノレポ化、パフォーマンス改善など基盤も推進

### 顧客開発・GTM

- 顧客インタビューの洞察を週次でプロダクトに還元
- アポイント獲得のため交流会営業を実施
- PR TIMES / SEO / 機能告知の発信設計を主導

## 使用技術

フロントエンド：TypeScript、React、Next.js、TailwindCSS、Jotai、Radix UI

バックエンド：TypeScript、Nest.js、Prisma

インフラ：AWS（ECS、S3、CloudFront、Route 53、Lambda、API Gateway 等）、AWS CDK、Vercel

データベース：MySQL（PlanetScale）
