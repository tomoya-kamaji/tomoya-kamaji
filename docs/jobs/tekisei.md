## 概要

新卒向けの適性検査サービスで、相性診断 API の設計から実装・テストまでを担当した。
複業マッチングプラットフォーム（正社員）と並行し、月 40〜50 時間の業務委託として稼働。

## 課題と判断

月あたりの稼働時間が限られるため、一度バグが出ると修正対応でリリースまでのリードタイムが大きく延びる問題があった。また、ベトナムのメンバーとの協業だったため、口頭のやり取りだけでは仕様の認識ずれが起きやすかった。

そこで、単体・結合テストを厚く書いてリリース前の手戻りを防ぎ、仕様はすべて英語のドキュメントに残して認識をそろえる運用にした。

## 成果

- NestJS による API の設計・実装・テストを一貫して担当
- バグによる手戻りを抑え、短時間稼働でもリリースのリードタイムを短縮した

## 使用技術

TypeScript、NestJS
