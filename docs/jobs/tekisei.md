## 概要

相性がわかる適性検査サービスの API 作成を担当。
設計からテストまでを担当した。

期間中は複業マッチングプラットフォーム（正社員）と並行して従事。

## 雇用形態

業務委託（月稼働 40〜50 時間）

## 主な担当業務

Nest.js による API 作成、設計からテストまでを担当。
ベトナム人メンバーがいたためドキュメントは英語で作成し、
仕様について齟齬が発生しないようにドキュメントに残すことを徹底した。

稼働時間が短く、バグが起きるとリリースにリードタイムが発生してしまうため、
テストを手厚く書くことでリリースのリードタイムを短縮した。

## 使用技術

TypeScript、Nest.js
